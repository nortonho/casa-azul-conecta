# Casa Azul Conecta

Site para organizar intenções de doação de alimentos, roupas e itens de higiene em Brasília, DF. Projeto da Atividade Extensionista II (Análise e Desenvolvimento de Sistemas, UNINTER).

- **Autor:** Norton de Assis Montalvão (RU 4111565)
- **Site:** https://nortonho.github.io/casa-azul-conecta/
- **ODS:** 1, 2 e 10

## Como funciona

A pessoa escolhe uma campanha, informa o que deseja doar e autoriza o contato. Os dados vão para um Google Forms e ficam em uma planilha com acesso restrito ao responsável pelo projeto, que entra em contato para combinar a entrega.

## Funcionalidades

- campanhas com filtro por categoria;
- formulário com validação, enviado ao Google Forms;
- navegação por teclado e alto contraste;
- layout responsivo.

## Executar

Abra `index.html` no navegador. Para usar outro formulário, altere `FORM_URL` e `ENTRY` no `app.js`.

## Privacidade

Os dados são usados apenas para combinar a entrega e ficam acessíveis somente ao responsável pelo projeto.
